# Compose RGB Color Picker

Small Android app built for a technical challenge in April 2026. Three sliders set the red, green and blue values; the screen shows the resulting color and its hex code, which can be copied to the clipboard.

- Kotlin and Jetpack Compose with Material 3
- Color state kept in a `ViewModel` and observed by the UI
- Single screen, no third-party libraries

Open the project in Android Studio and run the `app` configuration.
